# Dataset Documentation

## Project
طراحی و پیاده‌سازی سامانه هوشمند سرقت علمی و تشخیص متون تولیدشده با هوش مصنوعی

## Purpose
این پوشه برای نگهداری و مستندسازی داده‌های موردنیاز دو ماژول پروژه استفاده می‌شود:
1. تشخیص سرقت علمی و شباهت متون
2. تشخیص متون تولیدشده توسط هوش مصنوعی

## Directory Structure

- raw/: داده‌های خام دریافت‌شده از منابع اصلی
- processed/: داده‌های آماده‌شده پس از پیش‌پردازش

## Dataset Information to Record

برای هر Dataset، اطلاعات زیر ثبت خواهد شد:
- نام Dataset
- منبع دریافت
- آدرس منبع
- زبان
- تعداد نمونه‌ها
- نوع برچسب‌ها
- مجوز استفاده
- تاریخ دریافت
- تغییرات انجام‌شده روی داده‌ها

## Data Management Rules

- داده خام در پوشه raw/ بدون تغییر نگهداری می‌شود.
- داده‌های پیش‌پردازش‌شده در پوشه processed/ ذخیره می‌شوند.
- منبع و مجوز استفاده از هر Dataset باید بررسی و ثبت شود.
- نتایج و تعداد نمونه‌ها بدون بررسی واقعی گزارش نمی‌شوند.
- Dataset نهایی پس از بررسی و هماهنگی اعضای پروژه انتخاب خواهد شد.
